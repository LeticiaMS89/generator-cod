# 💻 Code Generator - Gerador de Código Inteligente

Um gerador de código profissional que cria templates prontos para produção em múltiplas linguagens e tipos de projeto.

---

## 🚀 Funcionalidades

- **7 Linguagens**: JavaScript, Python, Java, C#, PHP, Go, Ruby
- **3 Tipos de Projeto**: Site, API, App Mobile
- **Recursos Extras**: Sistema de Login, Banco de Dados, CRUD Completo
- **Prompt Livre**: Descreva o que quer e gere código customizado
- **Copiar & Baixar**: Copie para área de transferência ou baixe o arquivo
- **Interface Moderna**: Design dark mode com sidebar e notificações

---

## 📋 Como Usar

1. Selecione o tipo de projeto (Site, API ou App)
2. Escolha a linguagem de programação
3. Marque as funcionalidades que precisa (Login, BD, CRUD)
4. Descreva o projeto no campo de texto (opcional)
5. Clique em "Gerar Código"
6. Copie ou baixe o código gerado
